# Malaysia Diaspora Network

A Gutenberg-native member portal and partner directory plugin. Provides a private space for members to access curated content, resources, and a searchable directory of partners — all built as native blocks.

## Description

This plugin adds three primary features to your site, delivered as Gutenberg blocks and patterns:

1. **Member Portal** — a gated area where members can browse blog posts, access a resource library, and explore partner listings.
2. **Partner Directory** — a dedicated, extensible directory module accessible from within the portal but managed as its own feature.
3. **User Registration** — front-end sign-up, login, and profile management for members, with role-based access to portal content.

Built for the block editor — every feature ships as configurable blocks you can drop into any page or template.

## Features

### Member Portal

- **User Registration & Accounts**
  - Member sign-up form (front-end)
  - Login / logout
  - Password reset
  - Profile page (view & edit own details)
  - Role-based access (e.g. member, partner, admin)
  - Optional: email verification, admin approval before activation

- **Blog Section**
  - Member-only posts and announcements
  - Categories / tags
  - Comments (optional)

- **Directory Section**
  - Entry point into the Partner Directory (see below)
  - Quick-access listings and featured partners

- **Library Section**
  - Downloadable files (PDFs, docs, media)
  - Organized by category / collection
  - Access control per file or group

- **Resources Section**
  - Curated links, guides, and external references
  - Tagged and searchable

### Partner Directory

- Partner profile pages
- Search and filter (by category, location, type, etc.)
- Admin-managed listings
- Optional partner self-service / submissions
- Featured / sponsored placements

### Gutenberg Integration

- Native blocks for every portal section (registration form, login, blog feed, directory grid, library list, resources)
- Block patterns for common portal layouts (member dashboard, partner landing page, etc.)
- Block variations and inspector controls for filtering, sorting, and styling
- Full Site Editing (FSE) compatible — works in template parts and theme templates
- `theme.json` friendly styling

## Installation

1. Upload the plugin folder to `/wp-content/plugins/` (or install via the plugin uploader).
2. Activate the plugin through the **Plugins** menu.
3. Configure settings under **Settings → [Malaysia Diaspora Network]**.
4. Add blocks to any page or template via the block editor.

## Requirements

- WordPress 7.X+ (Gutenberg / block editor)
- PHP X.X+
